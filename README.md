This is a script to add a local Gemini client to an LXC in Proxmox, as well as pulling environment data from Proxmox.

It allows key words to trigger a python script that interfaces with Proxmox to display CPU, Remory and storage statistics.

Requires a Gemini API key to run.

Backs up onto a small local 0.5B LLM if it goes offline

Install with  - 


bash -c "$(curl -fsSL https://raw.githubusercontent.com/Lythieus/Lyth-AI-Assistant/main/lyth-ai-assistant%2003.sh)"
